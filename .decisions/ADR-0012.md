# ADR-0012: Capture Google Analytics requests alongside Adobe Analytics

- **Date:** 2026-11-02
- **Category:** Product / Scope
- **Status:** Accepted
- **Importance:** normal
- **Scope:** `extension/**`, `docs/spec/**`

## Context

The extension observed only Adobe formats; users need the same timeline for GA4 and legacy Universal Analytics requests, including calls fired by GTM.

## Decision

Detect GA4 g/collect and browser-visible Measurement Protocol requests, plus Universal Analytics collection paths, by path and version/measurement ID. Decode their common fields in the existing event model. Treat GTM as the sender of destination tracking calls rather than a separate hit source; ignore container script loads.

## Consequences

First-party endpoints with standard paths work; arbitrary vendor tags and custom paths need user patterns. Browser-invisible server calls remain out of scope. Measurement Protocol api_secret is always masked before storage.
