# ADR-0001: Browser-only persistence: IndexedDB for recordings, chrome.storage.local for settings

- **Date:** 2026-11-02
- **Category:** Data / Storage
- **Status:** Accepted
- **Importance:** normal

## Context

Concept left open: browser-only vs local Python/FastAPI + SQLite backend; fixed stack is plain HTML/CSS/JS.

## Decision

No local backend. Sessions, tabs, navigations, requests and events in IndexedDB; settings, filter profiles and funnels in chrome.storage.local; unlimitedStorage permission.

## Consequences

No extra runtime, no localhost security boundary. Revisit only if a demonstrated browser limitation appears.
