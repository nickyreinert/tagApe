# ADR-0011: Funnels removed; journeys are split by user-set breakpoints instead

- **Date:** 2026-11-02
- **Category:** Product / Scope
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0005

## Context

User wants fewer tabs and finds rule-based funnels less useful than marking journeys while recording.

## Decision

Remove the Funnel view, editor and evaluation. Journey and Funnel tabs go away; grouping moves into Live. Journey breakpoints (T-012) replace funnels.

## Consequences

Stored funnel definitions are ignored. Config export no longer contains funnels.
