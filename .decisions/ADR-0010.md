# ADR-0010: Optional Adobe API lookup of dimension/metric names via a pasted Workspace curl

- **Date:** 2026-11-02
- **Category:** Product / Scope
- **Status:** Accepted
- **Importance:** high

## Context

Users want friendly names (eVar13 = Page Title) next to decoded variables. The specs ruled out Adobe credentials, the Reporting API and network calls by the extension.

## Decision

- Settings accepts a pasted Workspace curl; the extension extracts its URL, auth and company headers and the rsid.
- On user action only, it requests the dimension and metric lists from the same API host. No other network calls.
- The bearer token is kept in chrome.storage.session (cleared when the browser closes), never in local storage or exports.
- Only the fetched names are stored locally; showing them is a toggle.

## Consequences

The extension now makes user-triggered network calls to Adobe and briefly holds an Adobe credential. Without a paste nothing changes. The API path is inferred from the pasted URL and may need adjustment.
