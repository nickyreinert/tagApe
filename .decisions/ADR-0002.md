# ADR-0002: Chrome is the only target browser

- **Date:** 2026-11-02
- **Category:** Architecture / Stack
- **Status:** Superseded
- **Importance:** normal
- **Superseded by:** ADR-0008

## Context

Side Panel API and background.service_worker are Chrome-specific; YAW template is cross-browser (gecko block, just dev defaults to Firefox).

## Decision

Target Chrome only. Remove the gecko block from the manifest when the extension is implemented; use just dev chromium.

## Consequences

Free use of chrome.sidePanel and other Chrome-only APIs; web-ext lint may warn about Chrome-only keys.
