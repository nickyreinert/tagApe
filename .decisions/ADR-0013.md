# ADR-0013: Use HitTrail as the extension name

- **Date:** 2026-11-02
- **Category:** Product / Scope
- **Status:** Superseded
- **Importance:** normal
- **Scope:** `extension/manifest.json`, `extension/sidepanel.html`, `README.md`
- **Superseded by:** ADR-0014

## Context

The extension now covers Adobe and Google Analytics. The old Adobe-specific and generic Journey Recorder names no longer describe the product. Tag Inspector and TagMonkey are already used by other products.

## Decision

Use HitTrail in the manifest, side panel title, README and architecture description. Preserve aajr storage keys, database name and export format identifiers so existing local recordings and configuration remain readable.

## Consequences

The visible Chrome extension name changes after reload. Existing data stays compatible; the internal aajr identifiers remain historical.
