# ADR-0006: SPA navigations tracked via chrome.webNavigation

- **Date:** 2026-11-02
- **Category:** Architecture / Structure
- **Status:** Accepted
- **Importance:** normal

## Context

Journey grouping by page must support single-page apps; webRequest only sees document loads.

## Decision

Use webNavigation.onCommitted (document), onHistoryStateUpdated and onReferenceFragmentUpdated (SPA) to create Navigation records with kind document|history|fragment.

## Consequences

Adds the webNavigation permission (install warning: read browsing history).
