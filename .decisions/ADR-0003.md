# ADR-0003: Raw payloads retained by default; recordings kept until deleted; no default masking rules

- **Date:** 2026-11-02
- **Category:** Data / Privacy
- **Status:** Accepted
- **Importance:** normal

## Context

Concept Q2, Q3 and default masking were open; raw inspection is a core use case.

## Decision

retain_raw defaults to true (toggle in Settings). Sessions are kept until the user deletes them; storage usage is shown. Masking rule list starts empty and is user-editable.

## Consequences

Storage grows with use; user must delete or export old recordings. Personal data in hits is stored locally unless the user adds masking rules.
