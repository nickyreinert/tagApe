# ADR-0008: Chrome is the only target; manifest carries Firefox keys only to satisfy web-ext lint

- **Date:** 2026-11-02
- **Category:** Architecture / Stack
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0002

## Context

web-ext lint (just check) errors without background.scripts and a gecko add-on ID; ADR-0002 removed the gecko block.

## Decision

Keep Chrome as the only target. manifest.json adds background.scripts (ignored by Chrome) and browser_specific_settings.gecko so web-ext lint passes.

## Consequences

Chrome may show an 'Unrecognized manifest key' warning for browser_specific_settings. No Firefox support is implied.
