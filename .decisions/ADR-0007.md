# ADR-0007: Both AppMeasurement and Web SDK are MVP sources; first-party Edge domains

- **Date:** 2026-11-02
- **Category:** Product / Scope
- **Status:** Accepted
- **Importance:** normal

## Context

Target environments use AppMeasurement on *.sc.omtrdc.net and Web SDK on first-party domains such as smetrics.<site>/ee/<region>/v1/interact; Web SDK hits carry AA variables in data.__adobe.analytics.

## Decision

Both parsers are MVP. Web SDK data.__adobe.analytics is decoded with the AppMeasurement value rules (events, products, D= references); XDM is shown separately and not merged into AA variables.

## Consequences

Web SDK moves forward in the implementation order; rsid stays null for Web SDK, datastream configId is shown instead.
