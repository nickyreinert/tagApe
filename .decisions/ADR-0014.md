# ADR-0014: Use TagApe as the extension name

- **Date:** 2026-11-02
- **Category:** Product / Scope
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0013
- **Scope:** `extension/manifest.json`, `extension/sidepanel.html`, `README.md`

## Context

The existing icon is a monkey, and the user prefers TagApe over HitTrail. A quick search found no obvious analytics extension with the exact TagApe name.

## Decision

Use TagApe in the manifest, side panel title, README and architecture description. Keep aajr storage keys, database name and export format identifiers for compatibility.

## Consequences

The visible extension name changes after reload. Existing recordings and configuration remain readable.
