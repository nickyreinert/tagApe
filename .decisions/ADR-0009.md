# ADR-0009: All-sites host access declared in host_permissions at install

- **Date:** 2026-11-02
- **Category:** Security / Access
- **Status:** Accepted
- **Importance:** normal
- **Supersedes:** ADR-0004

## Context

With <all_urls> only in optional_host_permissions, webRequest events did not wake the stopped MV3 service worker; hits were lost unless DevTools kept it alive. Chrome also warns that webRequest needs manifest host permissions.

## Decision

Declare <all_urls> in host_permissions. Start still calls chrome.permissions.request, which only prompts if the user withheld site access.

## Consequences

Install shows the all-sites warning. Capture survives worker shutdown. Revoked site access still shows the header banner.
