# ADR-0004: All-sites host access requested at runtime when a recording starts

- **Date:** 2026-11-02
- **Category:** Security / Access
- **Status:** Superseded
- **Importance:** normal
- **Superseded by:** ADR-0009

## Context

Tracking servers are often first-party domains, so detection needs <all_urls>; option was declared vs optional permission.

## Decision

Declare <all_urls> in optional_host_permissions and call chrome.permissions.request from the Start click (user gesture) if not yet granted. Recording does not start without it.

## Consequences

No all-sites access at install; one prompt on first Start; UI needs a permission-denied state.
